# Android 设置（系统设置）常用操作

适用：需要开启开发者选项、无线调试、无障碍服务，或把应用加入电池优化白名单时。不同厂商的入口名称略有差异，下面是通用路径与备选说法。

## 开启开发者选项

目标：让「开发者选项」出现在系统设置里。

步骤：
1. 打开「设置」→ 拉到底部 →「关于手机」（部分机型叫「关于设备」「我的设备」）。
2. 找到「版本号」（也可能叫「MIUI 版本」「内部版本号」），连续点击 7 次。
3. 输入锁屏密码后，提示「已进入开发者模式」。
4. 返回设置上一级，会出现「开发者选项」（小米在「更多设置」里，华为在「系统和更新」里）。

注意：找不到「版本号」时先点开「全部参数」再找；部分机型把点击次数限制在锁屏后 10 分钟内生效。

## 开启无线调试

目标：让电脑或 MCA 通过 Wi-Fi 连接此设备做调试，不必插 USB。

步骤：
1. 「设置」→「开发者选项」→ 打开「USB 调试」。
2. 在同页打开「无线调试」（Android 11 及以上；更早版本名称为「ADB over network」）。
3. 点「无线调试」进入详情页，选「使用配对码配对设备」，记下显示的 IP、端口与 6 位配对码。
4. 回到详情页，记下「IP 地址和端口」，供后续连接使用。

注意：无线调试必须在同一 Wi-Fi 下；配对码只在弹窗期间有效，关掉就失效；部分机型每次开关 Wi-Fi 都会更换端口。

## 开启无障碍服务

目标：让自动化能力读取屏幕内容并执行点击。

步骤：
1. 「设置」→「无障碍」（部分机型在「辅助功能」「更多设置」里）。
2. 找到「已下载的应用」「已安装的服务」或「已下载的服务」。
3. 点目标应用名称，打开开关，弹窗选「允许」。

注意：从 GitHub 等非商店渠道安装的应用，Android 可能显示「受限设置」，需要先在应用信息页点「允许受限制的设置」再回来开启；开启后服务崩溃会自动关闭，需要重新打开。

## 电池优化白名单

目标：避免系统在后台杀掉长任务。

步骤：
1. 「设置」→「应用」→ 找到目标应用 →「电池」（或「电池优化」）。
2. 选择「不限制」「无限制」或「允许后台活动」。
3. 再回到「设置」→「电池」→ 关闭该应用的「省电策略」「智能省电」等单独开关（厂商命名不同）。

注意：这一项只降低被杀概率，不是保证；部分机型还有「自启动」「后台弹出界面」两个开关需要一起打开。

## 通用注意

- 设置页标题随厂商本地化变化，找不到时用设置内的搜索框直接搜「开发者」「无障碍」「电池优化」。
- 逐层返回确认路径，不要用 Home 键跳出，否则会丢失当前层级位置。
- 修改与安全相关的开关（USB 调试、无障碍）前，先向用户说明影响再操作。
