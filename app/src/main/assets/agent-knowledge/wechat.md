# 微信（WeChat）常用操作

适用：需要在微信里找联系人、翻历史聊天、发消息或进入群聊时。所有操作都靠读屏文字与点击完成，不依赖账号接口。

## 找联系人并发消息

目标：给某个指定的人发一条消息。

步骤：
1. 打开微信，确认底部停在「微信」标签页。
2. 点顶部搜索框（放大镜图标），输入对方昵称或备注名。
3. 搜索结果里先看「联系人」分组，点中头像进入聊天页；不要点「聊天记录」分组，那会跳到旧会话。
4. 在底部输入框输入内容，点右侧「发送」。

注意：备注名和微信名可能不一致，优先用备注名搜；同名联系人先看头像或最近聊天时间，再决定点哪一个。

## 翻聊天记录

目标：在某个会话里找到较早的消息。

步骤：
1. 进入该会话，从消息列表中部向上滑动（向下拖动手指），越往上时间越早。
2. 需要跳到更早时，持续上滑到顶部，会出现「查看更多消息」之类的入口，点它继续加载。
3. 想直接定位，用会话内搜索：右上角「…」→「查找聊天记录」→ 输入关键词。

注意：一次上滑不要幅度过大，屏幕会惯性滚动很多屏，容易错过目标；加载更多时等列表停止抖动再继续。

## 进入群聊

目标：打开某个群并发言。

步骤：
1. 在「微信」标签页的会话列表里按群名查找，或搜索框输入群名。
2. 点进群聊后，先确认顶部标题是目标群名（有的群名带后缀，容易点错）。
3. 发言同样走底部输入框与「发送」。

注意：群消息滚动很快，发言前确认没有新消息把输入框顶走；群名含表情符号时，搜索用其中连续的中文或数字片段更容易命中。

## 通用注意

- 微信的按钮文字是中文，且部分按钮只有图标（放大镜、加号、更多），点击前先用读屏确认控件描述。
- 页面切换有约 0.3–1 秒动画，点击后等界面稳定再找下一个控件，否则容易点在上一页的残留位置。
- 涉及支付、转账、红包、登录验证码时不要自行操作，交给用户处理。
