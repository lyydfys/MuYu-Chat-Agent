## Facts the plan assumes that source does not prove

1. **`onOpenAgentWorkspace` does not exist.** The architecture chain (`MCA_AGENT_V1_ARCHITECTURE.md:829-835`) starts from "ChatScreen 的 onOpenAgentWorkspace", but the drawer only exposes ChatScreen-local `onOpenImages` and the tuning shell action; all workspace plumbing must be new.
2. **Images does not demonstrate a shell/tab route.** It stops at `ChatScreen.showImages`; it is not evidence that a drawer row can reach `host.onTab`, nor that `MainChatScreenActions` already has a generic "open feature" path.
3. **Tab persistence is not ordinal-backed.** No `ordinal`/name persistence exists in `app/src/main`; the warning at architecture `:837` is precautionary. Restart/process-death tab restore cannot be claimed from source.
4. **A fifth tab overlay is not a drop-in.** `MainShellMotionContractTest` asserts exactly four overlays/keys/holder pairing; the plan must either update that contract or choose a non-overlay presentation. No source states which is intended.
5. **Adding a required `ChatShellActions` field is a breaking change.** There are only three construction sites, one of them the only test that builds the shell bundle by hand (`ProductionImageGalleryWorkflowTest.kt:109-116`); the "defaults must never be relied on" rule (`ChatViewModel.kt:345-349`) conflicts with a compat no-op default. No source decides this.
6. **No existing drawer test covers row order, labels, or a new tag.** `drawer.agent_workspace` and "打开 Agent 工作区" are plan text only (`MCA_AGENT_V1_ARCHITECTURE.md:839`); no `drawer.*` tag exists and no test asserts the image row's position.
7. **No feature-level Compose UI test lane exists.** `feature:chat`/`feature:agent` have no androidTest source/deps; only `:app` can host Compose UI tests. The untracked `feature/agent-workspace/build.gradle.kts` declares androidTest deps but has no `src/`, so it is not evidence of tests.
8. **`verify-code.ps1` does not fully cover the new modules.** No `-AgentTests`; compile lane omits feature modules; baseline `-Changed` has no agent-module mappings, and a later dirty-tree edit adds only test-task mappings (no compile/`-FullTests` coverage); the untracked `agent-verify.ps1` is not the official gate. A green `verify-code` run would not compile/verify a new workspace module unless it is added to the graph/tasks or Gradle builds it transitively.
9. **Visual equivalence is unproven.** There is no golden-screenshot diff harness; existing screenshot captures are ad hoc. Without a real device render (hard lock `:232`; architecture `:873`), the required before/after and light/dark/large-font checks are NOT_RUN; this recon was not authorized to run adb, so no device render was performed.
10. **`MainUiEffect.NavigateToTab` is not a navigation mechanism.** It is defined and unit-tested but never emitted/collected in main source; it cannot be cited as an existing host route.
11. **App-menu actions do not uniformly close their overlay.** "智能调参" passes `onOpenAgent` straight through (`ChatAuxiliaryPages.kt:178`) while image/assistants wrap with `closeMenu()` (`:186-194`); "drawer closes before switching" is only proven for the drawer rows, not for the app menu.
12. **Icon choice is not proven.** "同 icon family 的既有合适任务/自动化图标" (architecture `:839`) names no icon; the drawer currently uses only `Icons.Default.Image` (`ChatHistoryDrawerScreens.kt:367`) and the app menu uses `Psychology`/`McaLogoMark` (`AppMenuScreens.kt:140-150`) — no task/automation glyph precedent in the drawer.
