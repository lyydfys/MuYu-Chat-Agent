# 内置网页预览

联网检索来源现在支持“应用内打开”。只有用户在来源卡片上明确点击后才会创建预览窗口；聊天页和联网检索诊断页共用同一个受限 WebView。

安全边界：

- 初始地址必须是 HTTPS，并且不能包含用户信息；`http`、`javascript:`、`file:` 和异常 URL 会显示错误，不会交给外部 Intent。
- 页面导航只能留在初始来源的主机或其子域名。跨域跳转会被拦截并显示“问题 + 下一步”。
- 禁用文件读取、内容 URI 读取、混合内容、多个窗口和下载回调；网页下载只显示提示，不在 MCA 内执行。
- WebView 没有 JavaScript bridge、命令执行入口或后台自动化能力。返回键先返回网页历史，再关闭预览。
- 工具栏提供刷新、缩小、放大和关闭，适配手机阅读；页面标题和当前地址可见，便于用户判断来源。

这不是通用浏览器，也不替代搜索服务。联网检索仍由已配置的搜索服务负责，内置预览只用于用户主动查看已返回的来源链接。
