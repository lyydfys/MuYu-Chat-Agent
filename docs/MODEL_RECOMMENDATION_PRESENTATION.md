# 模型推荐页信息展示

推荐页按用户选模型的需要组织信息：模型用途、格式、规模与量化、运行后端、功能、建议内存和下载大小。

- 所有可下载模型的主按钮统一为“下载”。已安装模型继续关联本地条目，提供打开或重新校验操作。
- 推荐卡片不展示实验、验收、待验证等研发状态，也不展示设备路径和下载策略。
- 模型名称、简短介绍和完整介绍使用相同的用户文案，不把开发过程、测试记录或底层调用链作为模型卖点。
- 卡片按原分类与顺序展示，每组仍默认显示一个模型，其余通过展开查看。
- 较长说明放在“完整介绍”中；实际缺失的模型文件、当前尚未实现的功能，以及明确的运行包差异如实说明。
- 下载大小来自模型包所有下载组件的源文件大小。无法得到完整体积时显示“见文件列表”，不以单个主模型代替完整包，也不把压缩包大小当成安装占用。可按设备选择不同包的模型，卡片显示参考体积。
- 已安装大小来自本地模型记录。建议内存独立显示，不由下载文件大小推算。
- 图片理解能力区分完整视觉组件、可选组件与仅文本安装；需另下视觉组件时给出明确说明。

本次调整保留内部目录状态、安装完整性检查、实际运行检查、模型包标识、下载地址、设备排序与默认加载策略。移除用户端的研发措辞不表示把所有内部状态改为已通过。

验证入口：`:feature:modelhub:testDebugUnitTest`、`:core:download:testDebugUnitTest`、`:app:compileDebugKotlin`。界面布局仍需在包含这些修改的 APK 上检查，旧 APK 不能作为新版界面证据。
