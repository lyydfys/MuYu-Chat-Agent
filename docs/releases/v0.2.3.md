# MCA v0.2.3

本版本集中改善启动白屏、模型下载后不可见，以及角色卡、世界书和生图使用体验。

## 更新内容

- 启动时先显示可操作的加载界面，将模型发现、旧记录迁移和配置读取移到后台。启动失败或上次启动中断时，可重试、暂缓模型扫描并复制诊断，保留模型和聊天记录。
- 推荐模型下载、校验、解压和导入改为持久后台任务。中断后可复用已完成文件及解压条目，提供暂停入口、低存储空间提示、注册失败恢复和本地模型保存位置。
- 本地模型分为聊天和生图列表，采用惰性列表加载；LiteRT-LM 推荐分类默认收起其余模型。完成注册后提供查看本地模型入口。
- 扩展 PNG 角色卡元数据的 URL-safe Base64 兼容；完善角色设定更新与当前对话的关联提示。世界书支持附加关键词、选择性匹配、正则和大小写配置，并展示启用状态及条目类型。
- 知识库检索保留长问题的开头和结尾，兼容部分英文词形变化，并改善绑定与检索状态提示。检索仍采用离线关键词方案，不宣称具备向量语义检索能力。
- 增加首次使用的模型选择/导入入口、独立快速开始页、加载阶段说明，以及包含下一步操作的错误提示。聊天背景移入应用菜单独立页面，菜单支持滚动。
- 兼容 SDXL CLIP 已投影序列的 EOS pooled 输出，保持拒绝未投影 hidden-state 替代值的校验。
- 修正图像模型固定尺寸、导入模型提示词计数路由和模型家族对应的输入容量。CLIP 模型保持 77 token；已支持长文本编码器的对应推荐包使用 512 token。移除生图词典自动补全，不把中文提示词静默改写成英文。
- debug smoke 测试调整到正确的 `testDebug` 源集，避免正式版本单测依赖 debug Activity。

## 升级与验证边界

请覆盖安装同签名版本以保留数据，无需卸载旧版。模型权重、密钥及用户数据不随 APK 分发。Android 强行停止会阻止后台任务运行，重新打开应用后才恢复调度；主动暂停及明确的存储/格式失败需要处理原因后重试。

本轮无在线 ADB 设备，尚未使用本次正式 APK 验证故障手机启动、前端下载导入、角色卡/世界书/知识库对话、生图质量和认证 Local API。旧版本真机记录不能替代这些检查。

本地生图及具体 QNN/QAIRT 模型包仍属实验能力。设备信息仅用于推荐排序和运行时选择；未知设备继续走通用兼容路径，实际文件完整性、原生加载和执行决定结果。
