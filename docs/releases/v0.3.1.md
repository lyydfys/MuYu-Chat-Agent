# MCA v0.3.1

**稳定化版本：修复预设导入与聊天历史丢失，落地“模型预设 + 角色卡覆盖”，并切换到 Apache-2.0。**

- 发布日期：2026-11-03
- 上一版本：`v0.3.0`（versionCode 9）
- 本版本：`0.3.1`（versionCode 10）
- 适用设备：Android `arm64-v8a`，minSdk 26
- 许可证：**Apache-2.0**（`0.3.0` 及更早版本仍为 MIT）

## 1. 重点修复

### 1.1 酒馆预设导入崩溃

Android 的正则实现会拒绝旧模式 `\{\{[^}]{1,160}}`，导入含 `{{char}}` / `{{user}}`
等宏的 Tavern 预设时直接抛出 `PatternSyntaxException`。本版：

- 改为合法的 `\{\{[^}]{1,160}\}\}`，并复用预编译模式；
- 同时修正 CRLF 被写成字面量 `\n`、NUL 字符未真正移除的问题；
- 实际预设文件（147 个 prompt、24,000 字符合并提示词）已通过解析测试；
- 设备侧探针确认旧模式报出同样的 index 16 错误，新模式正常删除宏。

### 1.2 聊天记录全部消失、记忆保留

旧会话写入用“UI 快照中不存在的会话”作为 prune 依据。一次加载如果因单行 JSON
损坏、数据库暂时不可读或历史 bounds 裁剪返回空/部分快照，下一次保存就会永久删除
真实历史；记忆表独立，所以表现为“聊天记录没了，但记忆还在”。

本版改为：

- **缺失不等于删除**：只有显式 `deletedSessionIds` 才会删除会话；
- 空快照没有显式删除时是无操作，不再清空数据库；
- bounds 只限制本次写入，不会裁剪历史；
- `loadRecords` 逐会话容错：一行损坏只跳过该会话并记录 `MCA-ChatHistory`，
  其余历史继续显示；
- 删除会话、删除最后一条会话和清空聊天仍走显式 destructive mutation 路径。

> 已经被旧版本真正 prune 掉的 SQLite 行无法从应用内恢复；本版防止再次发生，
> 并让仍留在数据库中的可解析行重新可见。重要数据请使用系统备份或导出功能。

## 2. 生成参数：模型预设 + 角色卡覆盖

- 模型预设（`ModelGenerationProfileStore`）成为语义默认值的权威来源；
- 角色卡 `paramsJson` 新增 `override_fields`，只保存用户明确覆盖的字段；
- 解析顺序：**角色卡覆盖 → 模型预设 → 全局/内建默认**；
- 聊天页参数面板只写模型预设，不再写角色卡；
- 角色卡编辑器显示模型预设值，提供“使用模型预设”；保存时按差异生成逐字段覆盖；
- 旧角色卡没有覆盖元数据时继续按整份快照运行，首次编辑保存后转为新模型。

详见 `docs/adr/0011-model-generation-preset-ownership.md`。
