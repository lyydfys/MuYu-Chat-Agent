MCA v0.2.1 is the first stable release built from the current local-runtime,
model-management, and Local API baseline. It ships a signed ARM64 APK; model
weights, provider accounts, API keys, and user content are not bundled.

## Highlights

- Updated the local `llama.cpp` runtime to b10262 and strengthened native load,
  recovery, cancellation, and error-reporting paths for local chat.
- Added full-session KV checkpoint persistence and persistent-prefix cache
  handling for compatible local chat sessions, reducing unnecessary prompt
  rebuild work after normal session transitions.
- Added per-model, per-runtime execution profiles with pending/active/LKG
  recovery, adaptive tuning, and safer model-load parameter boundaries.
- Restored external GGUF and MNN import paths, improved MNN multimodal support,
  and expanded recommended local model metadata and download handling.
- Added scoped chat background images and persisted chat appearance settings.
- Added in-app GitHub Release update checking with SHA-256, package name,
  version, and ABI validation before opening the Android installer.
- Refined the image page sample cards with optimized English prompts and
  per-template English negative prompts; tapping a sample fills both fields.
- Completed the production plumbing for local image generation across
  `stable-diffusion.cpp`, MNN-Diffusion, and QNN/QAIRT bundle workflows,
  including image history, input handling, worker isolation, cancellation, and
  Local API integration.
- Added QNN/QAIRT runtime staging, graph diagnostics, and verified native
  bindings. Device information only ranks a package or selects transport;
  every user-facing action falls back to the compatible path and real native
  load/graph execution determines the final result.
- Hardened the authenticated OpenAI-compatible Local API, model lifecycle, and
  isolated worker protocols used by local chat and image operations.

## Validation

- Full `testDebugUnitTest` matrix passed on JDK 17.
- Signed `:app:assembleRelease` passed for `arm64-v8a` with the QAIRT SDK
  configured; MNN vendor provenance, MNN runtime stamp, and typed QNN headers
  were verified during the build.
- The published APK was verified with APK Signature Scheme v2 using the MCA
  release certificate. Its SHA-256 checksum is supplied as a release asset.
- On 2026-08-22 the `v0.2.1` assets were rebuilt from `3eb75c61` and replaced
  in place with the same filenames; no new release tag or APK asset was added.
- On 2026-08-22 the `v0.2.1` assets were replaced again from `e32dc62` to
  include the refined English image templates and negative prompts.
- Earlier formal production-surface regressions cover `MainActivity` and the
  authenticated Local API for MNN vision and the Qwen3.6 sparse-MoE local chat
  route. Their device evidence remains recorded in
  [MCA_REAL_DEVICE_REGRESSION.md](../MCA_REAL_DEVICE_REGRESSION.md).

## Upgrade Notes

- Install the v0.2.1 `arm64-v8a` APK over a previous MCA installation signed
  with the same certificate to retain application data.
- Existing local models are not changed or redistributed. If a model package is
  corrupt, incomplete, missing a required binary, or fails its real native
  load/graph smoke, MCA reports that concrete failure instead of treating an
  unlisted device as unsupported.
- Local image generation and individual QNN/QAIRT model bundles remain
  experimental. Their runtime behavior depends on the downloaded package and
  real execution on the device; do not treat them as a blanket performance or
  compatibility guarantee.
- Keep Local API LAN access limited to trusted networks. The generated API key
  is private and is not included in release material.
