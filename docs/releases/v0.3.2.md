## 0. 闪退修复

### 0.1 云端模型一点发送就闪退

发送链路取活动会话用的是 `chatSessions.first { ... }` 加 `requireNotNull(snapshot)`。当活动
会话 id 指向一个已不在列表里的会话（存储读取失败、旧快照恢复出的已删除会话、并发重置）时，
这两行在生成的协程里抛出 `NoSuchElementException` / `IllegalArgumentException`，异常逃逸成
未捕获异常，进程被系统直接杀掉。

本版：

- 两处改为可失败查找，失败时走既有收敛路径（状态栏提示「当前会话缺少角色信息…」+ 终止本轮）；
- 两个提交协程（多附件预检与常规路径）补上异常收敛，提交前任何异常都变成可见状态行。
  此前它们只有 `finally`，上下文组装、准入或会话持久化抛错都会直接崩进程；
- 上下文摘要阶段的 `checkNotNull(cloudConfig)` 改为显式取消，模型在压缩途中被删除不再 NPE。

### 0.2 同批排查的易闪退点

| 位置 | 原写法 | 触发条件 |
| --- | --- | --- |
| 选中助手读取 | `assistants.first()` | 助手列表为空（存储损坏或首次启动） |
| 删除助手 | `remaining.first()` | 删掉最后一个助手 |
| 失败回滚恢复会话 | `durableSessions.first { }` | 回滚目标会话已不存在 |
| 回放投影 | `blockBranches.first()` | 空块列表 |
| Markdown 渲染 | `urlMatchAt(index)!!`、`token[0]` | 空匹配 / 空 token |
| 生图提交 | `generatedImages.first()` | 生成结果为空集 |

全部改为容错回退（跳过、回退默认值或走失败收敛），不再抛异常。

## 1. 批量导入

- **世界书**：选择器改为多选（新增 `OpenAnyDocumentsContract`，MIME 仍为通配，避免部分
  OEM 文件管理器隐藏文件）。逐本读取与提交，单个文件损坏不影响其余，状态栏报告
  「已导入 N 本世界书，M 本失败：…」；
- **生成预设**：预设页「导入预设」改为多选，一次选择只做**一次**存储读改写，状态行报告
  导入数量与失败明细；
- 预设删除与绑定保存移到 IO 线程（此前在点击回调里同步做 SharedPreferences 与
  profile store 磁盘写入）。

## 2. 生成预设管理

酒馆（SillyTavern）文本生成预设从「一次性导入」变成可管理的资产：

- 应用菜单新增「预设管理」入口，进入独立全屏页面；模型管理页新增「预设」分节，
  两个入口读取同一批记录、共用同一套写入；
- 支持导入、重命名、绑定本地/云端对话模型、删除；
- 预设只保存采样与输出参数（温度、top_p、top_k、输出长度、惩罚项、停止词等）；
  提示词、模板和宏仍由角色卡导入；
- 绑定保存后把预设的语义字段写进对应模型的生成参数档案，**模型档案仍是运行时权威**，
  角色卡覆盖依旧优先于预设；
- 记录写在独立命名空间 `mca_generation_presets_v1`，带 schema 版本字段，逐条容错解析，
  不猜测旧格式，也不改写任何既有配置文件；
- 删除预设不会回退已应用到模型的参数，弹窗与状态栏都已写明。

## 3. 云端生图引擎可拉取模型列表

此前只有云端**聊天**引擎能在编辑器里「获取模型列表」，**生图**引擎必须手敲模型名。

- 图像引擎编辑器新增「获取图像模型列表」按钮，结果进入同一个可点选的模型选择弹窗
  （弹窗标题按类型区分「选择图像模型 / 选择推理模型」，点击直接写回对应模型字段）；
- 图像表单使用独立的 `imageApiFormat`，因此不复用聊天传输层：DashScope 原生根地址
  （`https://dashscope.aliyuncs.com`）的模型列表在 OpenAI 兼容前缀
  `/compatible-mode/v1/models` 下，直接请求原生根会 404，本版自动补正；
- 兼容 `data[].id`、`models[]` 和纯字符串等常见返回结构，去重后最多 256 条；
- 只读操作：拉取不占用表单状态栏，失败信息显示在按钮下方。

## 4. 设置页改为分区仪表盘

这是一次**结构性改版**，改动面比前几项都大（`SettingsScreens.kt` +1,055 行）。

**布局**

- 六个分区从一条横向标签条改为**仪表盘卡片网格 + 全屏详情页**；
- 分区标题微调：`日志/诊断` → `日志与诊断`；每个分区新增一行说明文案
  （运行=模型加载/生成参数/后端与内存、日志与诊断=运行日志/API 日志/诊断导出、
  隐私与数据=本机数据清理与缓存边界、联网检索=搜索服务/触发策略/来源质量、
  实验功能=仍在打磨的能力、关于=版本更新/开源许可/项目信息）；
- 顶部新增 Hero 卡片：`LOCAL INTELLIGENCE` / `本地智能，一处掌控` /
  「把模型、数据与联网能力的边界留在设备上」，并带三枚实时状态胶囊
  （状态·运行中/待机、模型·当前加载的模型名、检索·已配置/待配置）；
- 头部副标题由「运行、日志、隐私、检索与关于」改为「模型、数据与联网能力的一站式控制台。」；
- 新增「配置中心」分区标题与「N 个分区」计数、「配置即时生效，敏感数据留在本机。」提示。

**状态与交互**

- 每个分区卡片带状态徽标：在线 / 加载中 / 待机 / 已停用 / 已配置 / 链接可用 / 待配置 /
  暂无 / 99+ 条 / 更新中 / 待安装 / 预览 / 版本号（随运行、日志条数、检索配置、
  更新状态实时变化）；
- 详情页支持**下拉手势**关闭（88dp 位移阈值、900dp/s 快速滑动、24dp 最小滑动距离，
  未达阈值回弹）、系统返回键返回仪表盘，分页滚动状态在切换中保持；
- 卡片按下有缩放与边框渐变动效，背景为径向渐变 + 点阵；
- 无障碍：卡片合并语义并朗读状态（`stateDescription`），点击标签为「打开{分区名}」；
  返回按钮读作「返回设置中心」，关闭按钮读作「返回聊天」；
- 响应式：宽度 < 350dp 或字体缩放 ≥ 1.3x 时网格自动切为单列。

**隐私清理控件**

- 清理 owner 是单飞槽位，并发请求会被丢弃。现在当其他清理占用槽位时，清理按钮与
  前缀缓存开关一律**禁用**而不是静默丢弃点击；
- 已武装的二次确认会在等待期间被撤销，避免等待结束后一次点击直接清库；
- 关闭持久化前缀缓存被单飞槽位挡住时，状态栏给出明确提示，不再出现「开关点了没反应」。

## 5. 应用更新下载加速

495 MB 的更新包在单连接代理下只有几十到几百 KB/s。

- 新增 8 路 HTTP Range 并行下载：分片级断点续传、每片最多 4 次重试
  （700ms × 次数退避）、`Content-Range` 与总长度校验、合并后原子移动、
  取消不被吞掉、进度发布 250ms 节流；
- `≥32 MB` 的资产先尝试并行，失败按 URL 逐个回退到原有单流下载；
- 通过受信任的资产 API 302 解析出 `release-assets.githubusercontent.com` CDN 直链
  （10 秒连接/读取、15 秒总超时、禁止自动跟随重定向，只接受白名单跳转）；
- 国内资产镜像切换到 `ghproxy.net`（`gh-proxy.com` 仍用于 API）；
- 关于页显示下载进度条、已下载/总量、实时速度与预计剩余时间（时/分/秒格式化）。

  此时仍需手填模型名；
- 并行下载依赖服务端支持 Range；不支持时自动回退单流；
- 本地模型、图片、视频后端未在本次重新跑真实推理，相关结论沿用 `0.3.1`。
