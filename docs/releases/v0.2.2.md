# MCA v0.2.2

MCA v0.2.2 is a local-runtime stability update focused on MNN CPU prompt-cache
correctness, Qualcomm LiteRT runtime packaging, and reproducible validation.

## Highlights

- Fixed CPU MNN `LinearAttention` prompt-cache rollback by recording exact
  recurrent checkpoints and restoring only a matching token boundary.
- Kept CPU MNN at high precision and OpenCL at low precision while preserving
  load-signature and finite-logits safety checks.
- Added real logits diagnostics, prompt-cache reuse diagnostics, rollback token
  accounting, and same-transcript cold-control validation.
- Fixed cache-history trimming and recurrent-state restoration for repeated,
  same-shape, and single-token requests.
- Added LiteRT Qualcomm runtime staging for V73, V75, V79, and V81 profiles.
- Hardened QNN HTP telemetry, MNN diffusion backend selection, Local API
  provider isolation, worker recovery, and runtime identity verification.
- Added host numerical tests, sampler contracts, prompt-history tests, protocol
  filtering tests, recurrent-cache equivalence tests, and LiteRT/QNN readiness
  tests.

## Validation

- MNN vendor commit: `d407447ed56c4121a11ccbd266dc184ca1ead0c2`.

  `074b6cd757937d0c41921dca2ba54be34c870346ff9373d65720687ad26af1a5`.
- Host CTest: 7/7 passed, including the real CPU recurrent-cache numerical
  test.
- Gradle validation: 2398 tests, 0 failures.
- Device validation covered MNN CPU/OpenCL, prompt-cache A/B and cold control,
  llama.cpp, LiteRT-LM CPU/GPU/NPU, MNN diffusion, QNN graph/semantic, Local

- Protocol positive literal-tag retention, UI touch traversal, Local API
  authenticated chat/concurrency cancellation, model import/download traversal,
  and some backend cancellation recovery remain separately identified as not
  verified in the full validation record.
