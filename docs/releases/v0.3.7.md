# MCA v0.3.7

**DSH 对齐第三批：顶部流式悬浮条、运行时可靠性、Keystore、插件目录。**

- 发布日期：2026-11-05
- 上一版本：`v0.3.6`（versionCode 15）
- 本版本：`0.3.7`（versionCode 16）
- 适用设备：Android `arm64-v8a`，minSdk 26
- 许可证：**Apache-2.0**

---

## 1. 顶部流式悬浮条

- 生成时贴在屏幕顶部显示**正在写的内容尾部**（1–2 行），工具调用显示成「▸ 运行命令…」这类人话
- 结束 6.5s 后淡出；左侧细进度条按已用时间走完（非无限旋转）
- **条内可直接审批危险命令**（脱敏命令名 + 允许一次 / 拒绝 + 30s 倒计时）；与悬浮球审批互斥
- 设置项：底色（浅/深/半透明）、不透明度 0.35–1.0、行数 1–2、位置；开关默认关

## 2. 运行时可靠性

- **Web 端口可配**（1024–65535，0 = 交给运行时）：启动前真实 `ServerSocket` 探测，被占用时按 +1…+10 回退，并显示「原端口被占用，已回退到 X」
- **刷新率上限**：跟随系统 / 60 / 90 / 120；设备不支持时降级并说明，不越级请求
- **看门狗**：15s 探测一次，连续 3 次失败触发受控重启（`stop()` → `restart()`），5 分钟内最多 2 次，之后退避并记日志
- **运行状态自检**：运行时进程 / Web 端口 / 网关 / 终端 PTY / DSH 配置目录五项，只有真有修复动作的项才给按钮

## 3. API key 加密

- 新增 `ApiKeyVault`：AES-GCM 加密，`v1:` 前缀格式
- 旧明文在启动时迁移；**解密失败保留原值**并标记不可用，不清空用户凭据

## 4. 插件目录（只读）

- 控制台列出官方 `profiles/web/package.json` 的 dependencies（名字 + 版本），标注「由官方插件管理器管理」
- 本版**不提供**安装/删除，避免与官方插件管理器争抢目录

## 5. 离线容器资产（工具）

- 新增 `tools/runtime/fetch-offline-runtime.ps1`：按固定 URL 拉取 proot 与 Ubuntu 24.04 arm64 rootfs 并打印 SHA-256
- 资产**不入 Git**（`.gitignore` 已排除）；要出带容器的包时先跑该脚本，再放进 `app/src/main/assets/offline/`
