# MCA v0.2.4

本版本完善推荐模型下载后的完整性和本机兼容性反馈，增加 QNN context
预检，并把推荐模型与本地生图 bundle 关联起来。

## 更新内容

- 下载完成后分别显示“文件完整性”和“本机执行兼容性”，并把大小、SHA-256、安装审计和可恢复失败状态传回下载页。
- 安装 QNN 图像包时读取 context 的 buildId、目标 SoC、HTP arch、QNN core/backend API、SDK 和当前 runtime，提前给出具体不兼容原因。
- QNN context 或包元数据无法完整证明兼容时标记为“实验包”，仍允许下载和安装，不使用设备白名单阻断未知设备。
- 推荐卡片关联本地 bundle，提供“已安装 · 重新校验”“打开本地模型”和“校验失败 · 重试”等入口。
- 为 SDXL QNN 2.28 和 Gen5 QNN 2.45 包补充目标 HTP/SDK 声明；当前 HTP V79 没有可验证的专用图像 context 时会如实显示实验包。
- 修正图片任务重试的模型快照绑定，避免使用旧模型记录或旧 prompt 执行证据。

## 验证边界

本次构建本身不替代真实设备验收。协议正样本字面标签、Local API 认证聊天
并发/stop-cancel、模型导入路径遍历、LiteRT cancel/failure recovery、llama
unload/reload 和 UI 触摸遍历仍需设备或环境条件允许时专项执行。

QNN 图像包的 SoC/HTP/SDK 兼容性由安装阶段实测 context metadata 和首次
native load/graph execution 决定；未找到匹配 HTP V79 context 时，应用保留
下载能力并显示实验包。
