## 1. 酒馆预设：宏与正则开始生效

之前只有采样值能导入，预设真正的行为（宏、输出改写、结构化块）都没生效。本版补齐前两项：

- **宏引擎**：`{{getvar}}`/`{{setvar}}`/`{{addvar}}`/`{{incvar}}`/`{{decvar}}`、
  `{{user}}`/`{{char}}`/`{{description}}`/`{{personality}}`/`{{scenario}}`/`{{persona}}`、
  `{{random}}`/`{{pick}}`/`{{roll}}`、`{{time}}`/`{{date}}`/`{{newline}}`、注释与 `\{{` 转义。
  未识别的宏**原样保留**（不静默删除）；最多 3 轮展开，输入 200k / 结果 400k 截断。
  变量按会话隔离，**重启即失**。
- **正则输出改写**：解析预设 `extensions.regex_scripts`，`placement=1` 作用于你的输入、
  `placement=2` 作用于助手输出；单脚本 200k、最多 64 条、每条最多 2000 次替换；
  非法正则跳过并记 warning，不影响其它脚本。
- 只有当前模型绑定了带这些配置的预设时才启用，否则行为与之前完全一致。

## 2. `<StatusBlock/>` / `<details>` 小剧场：结构化显示

- 识别并渲染成折叠卡 / 键值两列 / 表格；`script`/`style`/`iframe`/`form` 等整段丢弃，
  **所有属性丢弃**（`on*`、`style`、`src/href`、`javascript:` 无法进入界面），
  **脚本永不执行**；未知块保留原文可展开。
- 上限：输入 200k、标签 500、嵌套 32；纯 Markdown 不误判。
- 设置 → 实验功能新增「富文本块显示」（默认开），每条消息仍可「查看原文」回退。

## 3. 备份：真正的行级恢复

- 导出现在包含**行数据**（凭据列在导出边界剔除并记录），不再只是清单。
- 恢复是**事务式**的：校验列 → 事务内 `DELETE`+`INSERT` → 提交前逐表行数比对 →
  任何失败整批回滚，**不会留下半恢复状态**；恢复前另存一份缓存快照。
- 世界书与助手卡是文件存储，**不在本备份范围**（UI 与清册都写明）。
- 设置页「恢复」不再是只校验，改为「恢复（覆盖当前数据）」+ 二次确认。

## 4. 上下文来源：知识库也显示名字

- 知识库名与文档名随 trace 持久化，来源面板优先显示记录名；
  库被删除后显示「原名（已不在当前资料库）」，UUID 只作为短面包屑。

## 5. ADB 无线配对（实验性，默认关闭）

按 AOSP 真实协议实现，而不是早期误以为的 TLS-PSK：

- 证书 TLS（自签 EC P-256，接受任意服务端证书，与 adb 一致）+ `ExportKeyingMaterial(64)`
- **Curve25519 SPAKE2**（BoringSSL 语义：M/N 取自 `spake25519.cc`、身份串含结尾 NUL、
  口令标量修正、transcript 8 字节小端长度、64B key material）
- 配对包：6 字节 header + 手写 protobuf（PeerInfo）+ AES-128-GCM 帧
- 成功只认**设备回包能被解开**；失败返回稳定原因码与未验证假设清单
- 四条线格式假设尚未在真机确认（见 `docs/architecture/DSH_ADB_PAIRING.md` 第 6 节），
  因此**默认关闭**；打开后可以手动尝试，失败原因会显示出来
- ⚠️ 控制台 UI 入口尚未接上（本轮只到通道层），下一版补
