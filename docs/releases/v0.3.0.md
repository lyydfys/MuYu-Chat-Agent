# MCA v0.3.0

本版本把 MCA 从“聊天 + 模型管理 + 生图”扩展为完整的本地 AI 工作区：
本地 Agent、内嵌 DSH 工作区、Wan 2.2 视频、MediaTek/Anima 与
Qwen-Image/GenieX 路线，并把 Wan 引擎的可复现构建产物收进仓库。

## 更新内容

- **本地 Agent**：新增 Agent 契约、运行时和工作区，支持工具调用、MCP、
  记忆、审批和工作流；与聊天 Provider、模型生命周期共享同一套所有权。
- **内嵌 DSH**：新增 10 个 DSH 模块、DSH gateway 和工作区，覆盖浏览器、
  无障碍/虚拟屏、Android actions、作业生命周期、维护和中断恢复。它是开发
  预览能力，Provider 凭据和工作区配置仍由用户控制。
- **视频工作区**：Wan 2.2 TI2V-5B 文/图生视频、外置
  `stable-diffusion.cpp` 引擎、模型资产下载与校验、Turbo LoRA、图编辑和
  前台生成。模型权重仍由用户下载，不随 APK 分发。
- **图像与加速器**：Qwen-Image 2.1、MNN-Diffusion、QNN/HTP、LiteRT
  Qualcomm、MediaTek NPUG/DLA、Anima CPU/NPU，以及 Anima v4 固定/动态包的
  许可确认、二选一、SHA-256 校验和断点续传。
- **模型中心**：推荐过滤/排序、变体选择、许可门、ModelScope/HF 镜像和
  可恢复下载；不按设备型号阻断下载或运行。
- **Local API**：认证的 OpenAI 兼容服务扩展到模型、聊天、图像、视频和
  capability 发现，新增对应的 golden 契约。
- **存储与 UI**：Room v35（10 个 schema 快照）、新的设计系统组件、页面级
  craft、无障碍和动效统一。
- **Wan 引擎入库**：`core/sd-native/prebuilt/wan-engine-arm64-v8a.zip`
  （46.6 MB）保存了 `libstable-diffusion.so`、`libmca_wan.so` 和
  `libggml-htp-mca-v79.so` 的精确字节；`unpackWanEngine` Gradle 任务在打包
  前按 `WAN_ENGINE_BASELINE.properties` 校验 SHA-256 并解压到 `jniLibs`。
  这样不需要 LFS，也不受 GitHub 100 MB 单文件限制；源构建仍由
  `docs/proposals/mca-native-video-workflow-v1/build-engine.sh` 复现。

## 验证边界

- JVM 门禁和 release 构建不等于全部真机验收。Agent 工具链吞吐、DSH
  双版本内容升级、Wan V1 全部规格、Anima step 6 等仍有 NOT_RUN/BLOCKED
  项，不能因为本版本通过门禁就宣称全部生产就绪。
- QNN、MediaTek 和实验图像包仍由首次真实 native load/graph smoke 决定
  兼容性；设备型号只用于推荐和记录，不构成下载/运行黑名单。
- Anima v4 衍生包在 ModelScope 按 CircleStone 非商业许可发布；本仓库不包含
  权重或 bundle ZIP。Wan 模型资产由用户在应用内下载。
