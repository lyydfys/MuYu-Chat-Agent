## 1. App 外显示：小鲸鱼悬浮窗

在 DSH 悬浮球菜单里新增「App 外显示」，开启后吉祥物成为系统级悬浮窗，DSH 在后台继续运行。

- **吉祥物常驻**：可拖拽、贴边吸附，位置按屏幕行程分数保存，旋转/分屏后自动重排并钳制在可用区域内
- **回复气泡**：只在「一轮回答结束且文本非空」时弹一次（流式片段永不弹），2s 节流 +
  30s 同文去重 + 时钟回拨保护；气泡 6.5s 自动消失，标记播一次「收到回复」的动效后回落；
  点气泡或标记回到对应会话，长按开状态面板
- **状态动效**：待机呼吸、生成中加速脉动、回复时一次性放大，只用一条无限动画，
  常驻也不会每帧做布局
- **后台保活**：复用一个前台服务保持 DSH 运行时，另加一层 UI 进程保护；进程被回收后
  按开关状态自动重挂窗口；通知与面板都有「停止后台运行」的显式出口
- **权限**：未授予「显示在其他应用上层」时不写开关、给中文提示与「去授权」入口，
  不会静默失败

## 2. 形象自定义

- 内置三款矢量形象：**小鲸鱼 / 小肥鱼 / 小猫**，全部用 Canvas 基元绘制，
  32–96dp 清晰、跟随主题、可随 APK 分发（不涉及第三方美术素材授权）
- 可调：尺寸 40–96dp、不透明度 0.35–1.0、气泡行数 0–5、是否提醒回复、是否可拖拽
- **自定义图片**：从相册选一张，复制到 app 私有目录（8MB 上限、内容哈希命名、只保留一张）；
  图片损坏或丢失时自动回落矢量形象并在面板里说明
- 配置存单个 SharedPreferences JSON，坏文档整体回落默认值——读配置失败永远不会让悬浮窗起不来

## 3. DSH 设备权限通道（Root 可用、ADB 骨架）

参考 DSHA 的设备能力模型，先落地「通道 + 白名单」地基：

- **Root 通道**：`su -c` 执行，必须有 `uid=0` 正向证据才算可用；默认 15s 超时、
  256KB 输出上限，`finally` 兜底销毁子进程，页面取消不会漏 `su` 子进程
- **危险命令守门人**：白名单而非黑名单兜底——先按引号/转义切成段，拒绝 `$( )`、反引号、
  `$` 展开、重定向、子 shell、花括号、后台执行等无法逐段校验的构造，再逐段查
  拒绝表 → 白名单「命令名 + 参数形状」。未知命令不放行；拒绝只返回稳定原因码，
  不回显用户命令，也不提供「仍然执行」开关；实际执行的是重新单引号转义后的串
- **ADB 通道：已实现「已信任密钥的明文 adb 通道」**——自带 ADB 协议客户端
  （24 字节报文头/CNXN/AUTH/OPEN/OKAY/WRTE/CLSE/CRC32/4096 分片）、
  2048 位 RSA 身份（PKCS#1 v1.5 + SHA-1 签名、adb 520 字节公钥格式）、
  socket 握手与 shell 流控；收到 `AUTH(TOKEN)` 先回签名，设备再索要时上传公钥并
  如实标记「待配对」（只有收到 `CNXN` 才算可用）；输出 256KB 上限、15s 预算、
  异常映射成稳定原因码。**无线调试的 SPAKE2 配对流程本版仍未实现**：需要先在设备上
  开启无线调试或 `adb tcpip 5555`，并在 `adb_keys` 里登记本 App 公钥
  （控制台会显示需要这一步）；有 root 的设备可用 Root 通道完成登记
- 控制台新增「设备权限」区块：通道状态、最近一次结果（只显示退出码与输出长度，
  不回显命令与输出正文）、授权说明；Root 只在你点「探测」时才请求授权
